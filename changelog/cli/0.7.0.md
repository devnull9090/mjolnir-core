# Forge packs, bots on every map, and scripts that load

**Date:** 2026-11-03
**Summary:** The CLI packages Forge packs, bakes the pathfinding and tasks bots need into each level, and makes a level's baked scripts load.

### Added

- **Forge packs.** `mjolnir forge pack` packages a Forge manifest and cooked
  containers as a `.mjolnir` file for the hub, optionally signed by its author.
- **Bots in baked levels.** `mjolnir level bake` generates the pathfinding,
  firing positions and area tasks bots use, and writes them to `bots.json`.
- **A level's own scripts.** A level file can bring its own scripts.

### Fixed

- **Baked scripts load.** Scripts in a baked level were dropped when the map
  loaded. They now run.
