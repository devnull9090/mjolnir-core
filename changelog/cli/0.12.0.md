# A map's walkable ground

**Date:** 2026-11-10
**Summary:** `mjolnir level navmesh` writes a map's walkable ground for bots and tests, `live objects` shows ammunition, and game types carry spawn set labels.

### Added

- **`mjolnir level navmesh`.** Writes a map's walkable ground as JSON from
  the AI pathfinding a level bake builds: the areas, the doorways between
  them, the walls, and every collision surface, scenery included. It is what
  `tools/bot` walks and sees with.
- **Ammunition and the weapon in hand in `mjolnir live objects`.** A weapon's
  row ends with its loaded and reserve rounds (`ammo 12/120`), and a
  player's or AI's row with the weapon it holds (`weapon 0x…`).
- **Spawn sets in `mjolnir megalo write`.** A game type's string table gets
  the spawn set labels (`spawn_set_0` to `spawn_set_15`), and
  `<out>.layout.json` lists them, so MJOLNIRLevelLoader can give each game
  type its own spawn points when a match starts.

### Changed

- **Halo 2 player starts name more.** `mjolnir cache stage` names Halo 2's
  own game types on a start (Headhunter, Juggernaut, Territories) and gives
  each start's spawn types: both, initial only or respawn only.
