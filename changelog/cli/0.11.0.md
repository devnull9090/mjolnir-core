# Same bake, same bytes

**Date:** 2026-11-08
**Summary:** Level bakes give identical bytes every run, Assault joins `mjolnir megalo`, and `map pack` stops when a level's machines aren't in the pack.

### Added

- **Assault in `mjolnir megalo write`.** `--mode assault` writes CE's Assault:
  CTF with one flag at a time, which the attackers carry to their own stand. A
  capture, or `--side-seconds` (default 300), swaps the sides.
- **Multiplayer data in `mjolnir live objects`.** For an object that isn't a
  unit and has multiplayer data, the team column shows its multiplayer type,
  owner team and label. That tells spawn points, teleporter ends and objective
  markers apart, and shows which team respawns on each.

### Changed

- **A level bake gives the same bytes every run.** Pathfinding seams with equal
  scores were ordered by a hash map, so every bake numbered hints and links
  differently. Ties now go by segment pair. A map without ties bakes as before.
- **`map pack` stops on a missing machine.** Every tag a level places from
  `objects\mjolnir\<code>\`, such as its machines and controls, now has to be
  in one of the pack's containers. Without them the map still loaded, but every
  gate, button and shield was gone.

### Fixed

- **`mjolnir live` on a joiner.** It now reads a joining PC's object table, whose
  entries don't repeat their own slot. Only an index past the table's end is
  refused.
