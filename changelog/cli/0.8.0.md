# Custom vehicles, scripted devices and CE's game types in the level tools

**Date:** 2026-11-05
**Summary:** The CLI carries a Custom Edition map's own vehicles, scripts and devices into a level, and writes King, Oddball, Race and CE's other game types.

### Added

- **Custom vehicles.** A level can place a vehicle of its own with `tag`.
  `mjolnir level machine-collision --plan` writes a CE vehicle's hull and tyres
  into its collision, and `mjolnir map pack` carries the map's
  `vehicle_sounds.json`.
- **A map's scripts and devices.** `mjolnir level bake` carries a Custom Edition
  map's buttons, gates and automatic doors, and `mjolnir compile --names` checks
  a script against a scenario's names.
- **More game types.** The Megalo tools write King, Oddball, Race and their
  variants.
