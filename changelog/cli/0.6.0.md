# Forge map variants, Forge palettes, and Halo 2 lifts in converted maps

**Date:** 2026-10-25
**Summary:** The CLI reads and writes Forge map variants (.mvar), bakes a Forge palette into each level, and carries Halo 2's lifts and jump pads into converted maps.

### Added

- **Forge map variants.** The Megalo crate reads and writes Halo Reach map
  variant files (`.mvar`) bit for bit, and `examples/mvar_summary` lists what
  one holds: objects, positions, labels and budgets.
- **Forge palettes in every baked level.** `mjolnir level bake` writes the
  scenario's map variant palettes, one per category (weapons, vehicles,
  equipment, scenery), so MJOLNIRForge can place them.
- **Halo 2 lifts, jump pads and vents.** `mjolnir cache stage` reads the
  physics phantoms that push players in Halo 2 maps (pills, boxes and convex
  shapes, with the marker each pushes along) and writes them to
  `placement.json` as `lifts`. The level generator puts them in the level
  file, where MJOLNIRLevelLoader 0.9.4 pushes players with them.
