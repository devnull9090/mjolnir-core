# Download the command line instead of building it

**Date:** 2026-08-09
**Summary:** The first published build of `mjolnir`, the command line that reads and edits the tags in your installed game. Until now the only way to get it was to install Rust and compile it yourself.

`mjolnir` is the tool the guides use to find a tag, print its fields, change a
value and bake the result into a container the game will load. It has always
been in the repository; it has never been something you could just download.

Now it is. Windows and Linux builds are published with every `cli-v` tag, each
one with a SHA-256 you can check, and Windows can install it through a package
manager:

```powershell
scoop bucket add mjolnir https://github.com/devnull9090/mjolnir-core
scoop install mjolnir
```

### Added

- **Prebuilt binaries for Windows and Linux**, attached to the release and
  mirrored on releases.mjolnircore.com. Unpack it, put it on your `PATH`, done —
  no Rust toolchain, no twenty-minute first compile.
- **Install and update with Scoop** on Windows, from the bucket in this
  repository. `scoop update mjolnir` moves you to the newest release.
- Every build is checksummed, and the checksums are published in the release
  notes as well as next to the download.

### Changed

- The getting-started and tag-editing guides now open with the download.
  Building from source is still supported and still documented — it is just no
  longer the only door.

### Known issues

- Only 64-bit Windows and 64-bit Linux are published. macOS builds are not, and
  `mjolnir poke` — which changes a value in the running game — works on Windows
  only regardless, since it attaches to the game process.
