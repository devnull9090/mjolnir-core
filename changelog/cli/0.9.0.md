# Animation graphs, package scanning and new game types in the level tools

**Date:** 2026-11-06
**Summary:** The CLI reads and writes animation graphs for any skeleton, scans and clones the game's packages, and writes Stalker, Reverse Tag and game types with traits.

### Added

- **Animation graphs.** `mjolnir jmad` reads a graph, rewrites it for another
  skeleton, and proves a round trip byte for byte. `mjolnir jmad child` cuts a
  graph down to the animations a map changes and names a parent for the rest, so
  a rider's graph is about half a megabyte rather than 111.
- **Scan the game's packages.** `mjolnir ue scan` prints the matching properties
  of every export of a class across the packages you name, for questions like
  which material instances expose a parameter.
- **Clone a package.** `mjolnir ue clone` copies a shipped package under a path of
  your own into an addition container. It can set properties, repoint an import
  and add to an earlier container. Nobody has yet loaded a cloned package in the
  game.
- **Script traits.** `mjolnir megalo write` writes game types that change a
  player's traits from a script, and adds `--mode stalker` and
  `--mode reverse-tag`. The Juggernaut gets its extra damage and melee.

### Fixed

- **Line tests on rebaked maps.** Collision built with `mjolnir level collision`
  now keeps the shipped game's frame for its 2D trees, which corrects the line
  tests on rebaked maps. Published maps keep their old tables until they are
  rebaked.

### Known issues

- **A game type with traits needs the launcher and mods from this release.**
  Launcher 0.21.0 and older refuse it, and an older map registry falls back to the
  default game type.
