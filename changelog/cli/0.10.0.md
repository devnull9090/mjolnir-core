# Map packs carry vehicle sound banks

**Date:** 2026-11-06
**Summary:** `mjolnir map pack` writes a vehicle's Wwise banks into the archive, and stops if a container's `.pak` holds anything but a bank of its own.

### Added

- **Vehicle banks in a map pack.** `mjolnir map pack` reads the banks from the `.pak`
  beside a container and writes them as `content/<container>/<id>.bnk`. The archive
  itself never holds a `.pak`, and the launcher builds one when it installs the map.

### Changed

- **A pack stops on a bad bank.** `map pack` refuses a `.pak` holding any other file, a
  bank the game ships, and a bank whose header doesn't match its name. These are the
  rules the hub and the launcher apply.
