# The Pelican Warfare game type

**Date:** 2026-11-21
**Summary:** `mjolnir megalo write --mode warfare` writes the Pelican Warfare game type: two teams, a drop from Pelicans and three capture sites.

### Added

- **`mjolnir megalo write --mode warfare`.** Writes the game type behind
  Pelican Warfare: a warmup until enough players have joined, a transport and
  drop phase, then three capture sites that score for the team holding them.
  `--minimum-players` and `--warmup-seconds` set the start,
  `--warfare-minutes` the length of combat, and `--allow-mounted-capture`
  lets players in vehicles capture and contest a site. The mods release
  builds its copy with this command.
