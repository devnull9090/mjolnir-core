# Assault, and a map's own vehicles in Forge

**Date:** 2026-11-06
**Summary:** Assault joins the game types on every map with Capture the Flag, and a Forge game on a converted Custom Edition map now starts with that map's vehicles.

### Added

- **Assault** (MJOLNIRLobby 0.22.0, MJOLNIRHud 0.16.1, MJOLNIRLevelLoader 0.12.0).
  One flag at a time: the attackers carry it to their own base while the
  defenders stop them. A capture, or five minutes on the clock, swaps the sides.
  It's under Capture the Flag on every map that has it.

### Fixed

- **A map's own vehicles in Forge** (MJOLNIRForge 0.4.3, MJOLNIRLevelLoader
  0.12.0). A Forge game on a converted Custom Edition map showed none of the
  map's vehicles. It now starts with the ones a Slayer game on that map would
  place, and they stay when you load a saved layout or go back to the map's own.
  Saving in Forge doesn't change what a match places: the host's vehicle settings
  still decide.
