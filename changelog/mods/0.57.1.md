# Your current name in game

**Date:** 2026-11-26
**Summary:** A name refreshed from Discord on the hub now reaches the game within five minutes, without restarting it.

### Fixed

In MJOLNIRLobby 0.34.5.

- **Hub names stuck on an old Discord name.** In multiplayer you are shown
  by your hub name, which the hub took from Discord when you first signed in
  and never updated. Signing in again now updates it, and so does the new
  Refresh from Discord on your hub account page and in the launcher's account
  menu. The game asks the hub who you are every five minutes, so a running
  game picks the new name up for your next match.
