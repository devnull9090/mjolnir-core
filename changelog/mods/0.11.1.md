# FIND GAMES shows a game's details

**Date:** 2026-10-02
**Summary:** FIND GAMES shows the host, map, game type, players and ping of the selected game again. They were missing whenever the hub had no ping estimate.

### Fixed

- **A game's details in FIND GAMES.** Selecting a game showed only its name:
  the host, map, game type, players and ping were missing whenever the hub
  had no ping estimate for it. They show again, and the hub now has the
  locations it needs to estimate ping.

### Changed

- **MJOLNIRLobby 0.4.1**: the fix.
