# Multiplayer needs an unmodified game

**Date:** 2026-11-21
**Summary:** Games with third-party mods can no longer join, host public or stay in multiplayer matches, and map screenshots in the game update when the hub's change.

### Changed

In MJOLNIRLobby 0.29.0.

- **No multiplayer with third-party mods.** In the 21 November playtest a
  player with a modded magnum fired faster than everyone else, because a mod
  in your game folder changes how your own game plays the match. MJOLNIR
  already finds mods it did not install (the launcher moves them aside while
  you play), but a game started from Steam kept them. Now, while the game
  finds any:
  - **JOIN and public hosting are refused**, with a line that names how many
    mods it found and says to play from the MJOLNIR launcher, which moves
    them aside.
  - **The host sends you back** to your main menu if you get into its game
    another way, such as a Steam invite.
  - **You leave a host whose game has mods,** with a message saying why.

  The check runs when the game starts. A join made right after starting waits
  a moment for it. If the check cannot run at all, multiplayer stays closed
  until you start the game from the launcher.

### Fixed

In MJOLNIRLobby 0.29.0.

- **Map screenshots update.** A map's screenshot was saved the first time the
  game showed it and never fetched again, so a new screenshot on the hub
  never reached the menus. The game now checks the hub's map list (at most
  every ten minutes) and downloads a screenshot that has changed.

### Notes

- **Map authors choose the screenshot.** On the hub, a map's manage page now
  has a star on each screenshot that makes it the one the game and launcher
  show. A new upload used to go to the end of the gallery and never became
  the cover.
