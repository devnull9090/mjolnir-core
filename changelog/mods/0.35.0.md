# Choose game types from their own screen

**Date:** 2026-10-24
**Summary:** Browse your map's supported game types with icons and descriptions, see the chosen icon in the lobby, and place objects from Forge's palette.

### Added

- **Game type picker** (MJOLNIRLobby 0.16.0). GAME TYPE opens a dedicated
  screen showing the modes available for your map, with matching icons,
  descriptions and team formats. Preview a mode, then SELECT to apply it.
  BACK, Escape or controller B keeps your current choice.
- **Game type icons in the lobby.** The selected mode's icon appears beside
  its name and changes with your selection.
- **Forge palette** (MJOLNIRForge 0.2.0). Use the arrow keys to browse the
  map's weapons, vehicles, equipment and scenery; Insert places the selected
  object at the cursor, ready to move. N duplicates the target. The Forge
  HUD shows the category and available objects. Older maps offer the kinds
  already in their palettes; newly baked maps can include the full arsenal.
