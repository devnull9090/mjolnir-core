# Steadier fireteam matches: no mass drops, no lost sounds, a smooth vote

**Date:** 2026-10-25
**Summary:** Fixes from the 2026-10-24 playtest: team games that ended at load, a mass disconnect, joiner sounds and crashes, kill floors, Halo 2 lifts and a lag-free vote.

### Fixed

- **CTF and Team Slayer ended the moment the map loaded** with three or more
  players (MJOLNIRLobby 0.17.2). The third player landed on a team the game
  type does not have, and the engine ended the match. Players now go red and
  blue in turn, and a player who joins later takes the smaller team.
- **A whole fireteam dropped at once** (MJOLNIRLobby 0.17.8). A player whose
  game dropped and who joined again before the host had closed their old
  connection was given a second copy of themselves, and the host's game
  closed every connection. The new join now waits for the old one to go.
- **A new player inherited the score and kills of the player who left that
  seat** (MJOLNIRLobby 0.17.3, MJOLNIRHud 0.12.1). Their tallies start at
  zero; a player who comes back to their own seat keeps theirs.
- **Players who left and joined a match again heard no reloads or grenades**
  (MJOLNIRLobby 0.17.6). The lobby took their new game as already set up for
  sound because it was on the same map.
- **Joiners could crash when the map changed** (MJOLNIRLobby 0.17.12). The
  lobby could set up a match's sound a second time, before or on top of the
  game's own setup. It now waits for the game, and only steps in for a
  player who joined a match already under way.
- **The post-game vote screen stuttered** for everyone (MJOLNIRLobby 0.17.7):
  it redrew every row four times a second and searched the whole game for
  the players each second. The menus lost a few milliseconds every 1.5 s
  for the same reason. Both now redraw only what changed.
- **The vote could pick a map someone in the fireteam does not have**
  (MJOLNIRLobby 0.17.10), leaving them at the main menu. Each player's game
  now tells the host which maps it has, and the vote offers only maps
  everyone has or can download.
- **Falling into Gephyrophobia's canyon did not kill** (MJOLNIRLevelLoader
  0.9.3). The game types our matches use have no falling death, so maps with
  a pit now have a kill floor.
- **The Killing Spree callout stayed on screen** (MJOLNIRHud 0.12.2) when it
  came just after a Triple Kill, and the medals behind it never showed.

### Added

- **Halo 2's gravity lifts, jump pads and vents push players**
  (MJOLNIRLevelLoader 0.9.4), each player's game pushing its own player.
  Lockout's lift carries you to the top floor as in Halo 2.
- **The scoreboard shows who is dead** (MJOLNIRHud 0.12.4): DEAD beside their
  name, dimmed, until they spawn again. `mjolnir_scoreboard on` keeps the
  board up.
- **The post-game vote mixes game types** (MJOLNIRLobby 0.17.13): not four
  Slayers after a Slayer game. Forge is never offered.

### Known issues

- Halo 2 lifts need the Halo 2 maps converted again: a map from before this
  release has no lift data, and its lifts still do nothing until its next
  release.
- Each vote option's own map picture comes with the next CE runtime release;
  until then the vote shows the one picture it always has.
