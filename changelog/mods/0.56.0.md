# Multiplayer games open public

**Date:** 2026-11-22
**Summary:** MULTIPLAYER now lists your game in FIND GAMES by default, and a PRIVATE choice holds for the rest of the session.

### Changed

In MJOLNIRLobby 0.30.0.

- **Your lobby opens public.** Opening MULTIPLAYER as the host lists the game
  in FIND GAMES, so players on the hub can find and join it without an
  invite. Press **PRIVATE GAME** to take it off the list.
- **A private choice sticks.** Once you pick PUBLIC or PRIVATE, the game keeps
  it until you quit, through matches and back to the lobby, instead of
  opening public again.
- **FORGE still starts private,** and starting it does not count as your
  choice, so the next lobby opens public again.

### Notes

In MJOLNIRLobby 0.31.0.

- **Test machines stay off the hub.** A PC marked as a development machine
  (a `mjolnir_dev.txt` file in the game's Saved folder) opens its lobby
  private and sends no match history to the hub, so test matches don't show
  up in public history. Players never have this file, so nothing changes for
  you.
