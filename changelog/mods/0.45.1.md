# Forge games show a map's own vehicles

**Date:** 2026-11-06
**Summary:** A Forge game on a converted Custom Edition map now starts with the vehicles a Slayer game on that map would place.

### Fixed

- **A map's own vehicles in Forge** (MJOLNIRForge 0.4.3, MJOLNIRLevelLoader
  0.11.1). A Forge game on a converted Custom Edition map showed none of the
  map's vehicles. It now starts with the ones a Slayer game on that map would
  place, and they stay when you load a saved layout or go back to the map's own.
  Saving in Forge doesn't change what a match places: the host's vehicle settings
  still decide.
