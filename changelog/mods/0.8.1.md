# MULTIPLAYER is part of the main menu

**Date:** 2026-10-02
**Summary:** MULTIPLAYER is now a real main menu button: it shows the moment the menu opens, looks like its neighbours, and leaves Remix where it was.

### Changed

- **MJOLNIRLobby 0.1.2** works with the main menu's own MULTIPLAYER button,
  which the CE runtime 1.0.3 adds between CAMPAIGN and PLAY CO-OP. It is
  there as soon as the menu opens, with the same styling, keyboard and
  controller navigation as the other buttons, and Remix keeps its own spot.
  Choosing it opens the multiplayer lobby as before.
- Without the updated runtime, MJOLNIRLobby still adds MULTIPLAYER itself,
  as it did before.

Update the CE runtime from the launcher's Multiplayer page to get the new
button (1.0.3).
