# The game tells you when MJOLNIR is out of date

**Date:** 2026-10-24
**Summary:** At the main menu, the game says when MJOLNIR, the CE runtime or your maps are out of date, and UPDATE AND RESTART updates through the launcher.

### Added

- **Out-of-date prompt** (MJOLNIRLobby 0.15.0). When the game reaches its
  main menu, at start and after each match, it asks the MJOLNIR launcher what
  is out of date: code mods, the CE runtime pack and installed maps. It also
  asks about mods MJOLNIR did not install. If anything turns up, a screen
  lists it. **UPDATE AND RESTART** opens the launcher, closes the game, and
  the launcher updates and starts it again. **NOT NOW** puts it away until
  the next visit to the main menu. It needs launcher 0.17.0; an older
  launcher is never started for it.
