# Bots

**Date:** 2026-10-29
**Summary:** The host can fill a match with AI bots that have names, show on the scoreboard and kill feed, and hunt players across the map. The lobby is tidier, and the map select has search.

### Added

- **Bots in multiplayer matches** (MJOLNIRHud 0.13.0, MJOLNIRLobby 0.18.0).
  The host sets BOTS (0 to 15), BOT TYPE (Spartans, Elites, Grunts, Jackals
  or a mix) and BOT DIFFICULTY (Normal, Heroic or Legendary) on the PLAYERS
  page of the game settings. Each bot gets a name such as "Nadia (bot)",
  shows on the scoreboard and in the kill feed like a player, respawns 5 s
  after it dies, and every few seconds either hunts a player or moves to
  another part of the map. Spartan bots wear the classic armour and carry a
  mixed arsenal, sniper rifle and rocket launcher included.
- **`/bots <0-15> [kind] [level]`** in match chat (host): change the bots
  during a match, for example `/bots 6 elites heroic`.
- **Every player in a fireteam sees the bots' names.** The host sends them
  when a player first meets a bot, and again whenever the bots change.

### Changed

- **A tidier lobby** (MJOLNIRLobby 0.18.0). The map and the game type are
  two tiles side by side: the host clicks one to change it. The game
  settings away from the defaults are a two-column list under them, so the
  card no longer runs down the screen as settings change.
- **Search on the map select** (MJOLNIRLobby 0.18.0). Type to find a map by
  its name, code or game: the list narrows as you type and picks the best
  match, and ENTER selects it. Double-clicking a map selects it too. Maps
  are listed by name with their game, and the one you are hosting is marked
  CURRENT; hovering a map previews it, and moving away shows your choice
  again.
- **Game types are a row of icons** on the map select. Hovering one shows
  what it is. SELECT and BACK sit at the foot of the map's details, where a
  long description can no longer cover them.

### Fixed

- **A match with bots ended at the score to win** (MJOLNIRHud 0.13.0): the
  game type only counted kills of players, so a playtest ran on to 37 of 25.
- **The scoreboard, kill feed and chat could show a terrain texture instead
  of a player's avatar** (MJOLNIRHud 0.13.0, MJOLNIRLobby 0.18.0) on the
  remastered maps.
- **The pause menu named "Assault on the Control Room"** on every converted
  map (MJOLNIRLobby 0.18.0). It now shows the map's own name.
- **The bot settings no longer make the level loader drop the host's game
  settings** (MJOLNIRLevelLoader 0.9.5).
- **The lobby names each team's vehicle settings** (MJOLNIRLobby 0.18.0):
  RED VEHICLES and BLUE GHOSTS, where both teams' read VEHICLE SET.

### Known issues

- Bots need the maps released with them and CE runtime 1.16.0, which has the
  bots' characters. A map from before has no bots, and the BOTS setting does
  nothing on it.
- The new lobby and map select screens are in CE runtime 1.16.0 too. With an
  older runtime pack they look as before.
- Bots walk, but do not jump, take lifts or use teleporters, so on maps with
  floors joined only that way (Lockout, Boarding Action, Chiron TL-34) they
  stay near where they spawn.
- Night Lockout has no bots yet: its floors are joined by short steps the
  bots' pathfinding does not cross.
- Bots are always on the AI's own side in team games, not on red or blue.
