# Make a match public or private while it runs

**Date:** 2026-11-08
**Summary:** Make a match public or private mid-match, from the HOST MENU or with /public and /private, and no more restarting a game to list it.

### Added

In MJOLNIRLobby 0.24.0 and MJOLNIRHud 0.19.0.

- **Public or private mid-match.** The HOST MENU has MAKE PUBLIC and MAKE
  PRIVATE, and chat has `/public` and `/private` for the host. A match made
  public is listed in FIND GAMES at once, and players can join it while it
  runs. A match made private comes out of FIND GAMES: everyone in it stays,
  and nobody new can join. Your chat says when the listing is up or down.
  FORGE matches stay private.

### Fixed

In MJOLNIRLobby 0.24.0.

- **A game that couldn't be listed until a restart.** A match started private
  with only you in the fireteam went offline, and your game never came back
  online on its own. Switching to PUBLIC GAME afterwards said "Not listed yet:
  no lobby yet" and nothing showed in FIND GAMES. Your game now stays online
  through a match whether it is public or private, so you can list it any
  time.
- **RETURN TO LOBBY brings an offline game back online.** If your game still
  ends up offline (FORGE does), RETURN TO LOBBY now leaves the match the way
  SAVE AND EXIT does, and your game is online again in the lobby.
- **The lobby says what's wrong.** An offline game no longer looks as if its
  listing is still on the way: the lobby says it went offline and how to
  bring it back.
