# Smoother remastered maps

**Date:** 2026-10-17
**Summary:** The remastered maps no longer stutter ten times a second, and the HUD now keeps a log of stutters that you can send us.

### Fixed

- **Stutter on the remastered maps** (MJOLNIRLevelLoader 0.7.1). On every
  remastered map except Rat Race, the level loader looked up the ground's
  footprint settings ten times a second. Each lookup held the game up for
  about 15 ms, which made a steady stutter. On Death Island, frames that
  ran long fell from 269 in 44 seconds to 28 in 52 seconds.

### Added

- **A stutter log** (MJOLNIRHud 0.8.0). The HUD times every frame on every
  map. A frame that takes much longer than the ones around it is written to
  `hitches.log` in the MJOLNIRHud folder, with where you were looking and
  which of MJOLNIR's scripts ran in it. Each map ends with a summary. If a
  map stutters for you, send us that file. `mjolnir_hitches` (console)
  writes the numbers so far.
- The level loader and the lobby (MJOLNIRLobby 0.13.2) report how long
  their scripts take to the stutter log.
