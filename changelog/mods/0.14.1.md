# A lobby that answers its buttons, and a reload that can't crash the host

**Date:** 2026-10-03
**Summary:** The lobby keeps trying to connect its buttons, and reloading mods no longer crashes a game in progress.

### Fixed

- **MJOLNIRLobby 0.7.1**: the lobby's buttons are hooked up again if the
  first try at startup failed, and when the lobby opens. Before, one failure
  left the lobby on screen with buttons that did nothing until the game was
  restarted.
- **Reloading mods no longer crashes the game.** MJOLNIRLobby,
  MJOLNIRLevelLoader and MJOLNIRBlamConsole each load a native DLL that
  hooks into the game. A UE4SS mod reload (Ctrl+R) unloaded those DLLs while
  the game still called their hooks, which crashed a host mid-match. The DLLs
  now stay loaded for the life of the game.
- Watching for the lobby is now the first thing the mod sets up, so a problem
  elsewhere in its startup can't leave the lobby without it.

### Notes

- Most "the buttons do nothing" reports were UE4SS itself not starting on
  slower PCs, which launcher 0.10.2 fixes.
