# Public games and FIND GAMES

**Date:** 2026-10-02
**Summary:** Hosts can make a multiplayer game public, and FIND GAMES lists public games to join without an invite. Games stay private unless the host opens them.

### Added

- **PUBLIC GAME.** The multiplayer lobby has a PRIVATE GAME button for the
  host. Switch it to PUBLIC GAME and your game is listed on mjolnircore.com
  with its map, game type and players, kept up to date while you play. Switch
  back, or join someone else's game, and it comes off the list. Every session
  starts private.
- **FIND GAMES.** Public games, nearest first: the map, game type, players,
  whether the host is in the lobby or a match, and an estimated ping. JOIN
  puts you in the host's fireteam the same way an accepted invite does. It
  tells you if you don't have the map.
- Both need the MJOLNIR launcher signed in to the hub. The lobby says so when
  it isn't.

### Changed

- **MJOLNIRLobby 0.4.0**: public games and FIND GAMES. The FIND GAMES screen
  comes with the CE runtime 1.0.5 from the hub; with an older runtime the
  button stays hidden.
