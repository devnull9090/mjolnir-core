# Forge checks layout files before loading them

**Date:** 2026-11-03
**Summary:** Forge checks a saved layout's label tables before handing it to the game, and refuses a malformed file with the reason instead of loading it.

### Fixed

- **Malformed layouts are refused** (MJOLNIRForge 0.4.1). Forge checks a
  layout's labels and their names before loading it. A file outside the
  game's limits is refused with the reason, for example "FRB.mvar refused:
  it has more than 256 labels", and the map plays its original layout.
  Layouts saved in game load as before.
