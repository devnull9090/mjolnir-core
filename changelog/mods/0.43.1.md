# Forge checks layout files before loading them

**Date:** 2026-11-03
**Summary:** Forge refuses malformed saved layouts with the reason instead of loading them, and automatic doors now open in Slayer and other game modes, not just Forge.

### Fixed

- **Malformed layouts are refused** (MJOLNIRForge 0.4.1). Forge checks a
  layout's labels and their names before loading it. A file outside the
  game's limits is refused with the reason, for example "FRB.mvar refused:
  it has more than 256 labels", and the map plays its original layout.
  Layouts saved in game load as before.
- **Automatic doors outside Forge** (MJOLNIRLobby 0.19.3). Door panels stayed
  shut in Slayer and every other mode because the door refused to move without
  Forge's map bounds. They now open and close in all modes.
- **Elites fit through low doorways** (MJOLNIRLobby 0.19.3). Once bots start
  in a match, elites stand a little lower, so they pass low doors.
