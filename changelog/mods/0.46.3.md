# Leaving means leaving

**Date:** 2026-11-07
**Summary:** A host who quits goes to the lobby, not a new match; the vote offers only maps that are really installed; a joiner without the map is told why.

### Fixed

In MJOLNIRLobby 0.23.0 and MJOLNIRLevelLoader 0.12.2.

- **Quitting started another match.** A host who chose SAVE AND EXIT could land
  on the post-game vote, and with nobody voting the next match started 20
  seconds later. Leaving a match now takes the host to the lobby with no vote.
  A match that ends on its own still votes and starts the winner as before.
- **The vote could pick a map that wasn't there.** A map listed but not really
  installed could win the vote, leaving the host on MISSION SELECT and everyone
  else on STARTING THE NEXT GAME. Such a map is no longer listed or offered, and
  if a chosen game can't start, everyone goes back to the lobby with the reason.
- **A joiner without the map saw only CONNECTION LOST.** When the host starts a
  map you don't have, or a different version of it, you still leave the
  fireteam, but now you're told which map it was and get its download screen:
  DOWNLOAD installs it without a restart, then you can join the host again. A
  kick from the host now shows the host's reason too.
