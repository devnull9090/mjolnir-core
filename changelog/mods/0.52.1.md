# Crash breadcrumbs

**Date:** 2026-11-15
**Summary:** The Level Loader now writes down each step of a map load as it happens, so when the game crashes we can see exactly what it was loading.

### Added

In MJOLNIRLevelLoader 0.13.16.

- **Crash breadcrumbs.** Every map load writes a short file,
  `ue4ss/Mods/MJOLNIRLevelLoader/breadcrumbs.txt`, with one line before each
  load step and each asset it loads. The game's own log is switched off in
  release builds, so after a crash this file is the only record of what the
  load was doing. If you report a crash, attach it.
