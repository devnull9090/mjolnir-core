# Join a game from the website

**Date:** 2026-10-10
**Summary:** Press Join on mjolnircore.com and the game joins that server from the main menu, downloading the map first when you don't have it.

Needs MJOLNIR Launcher 0.13.0, which receives the website's Join link and
starts the game when it isn't running.

### Added

- **Join from the website** (MJOLNIRLobby 0.11.0). Join on the Games page,
  or in the "Live now" strip on Match history, hands the server to the
  game. Once you're signed in at the main menu, FIND GAMES opens with that
  server picked and joins it.
  - A map you don't have downloads first, as DOWNLOAD AND JOIN does in game.
  - A server that has ended or filled up says so instead of joining.
  - A join that arrives during a match waits until you're back at the menu,
    for up to ten minutes.
