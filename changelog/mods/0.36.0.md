# Share your game and public invites on Discord

**Date:** 2026-10-24
**Summary:** Show your map, game type and observed kills and deaths as MJOLNIR Core on Discord, with Join Game for public sessions that have room.

### Added

- **Discord Rich Presence** (MJOLNIRLobby 0.17.0 and MJOLNIRHud 0.12.0).
  Discord shows the current map, game type, observed local kills and deaths,
  and time in the session. Menus and post-game states clear old match stats.
- **Join Game for public sessions.** Public sessions with room can show a
  join action on the host's and participants' profiles. Joining uses the
  existing MJOLNIR sign-in and map checks. Private, full, offline, stale,
  and non-joinable sessions do not advertise a join action.
- Presence reconnects when Discord restarts. To disable it locally, create
  `MJOLNIRLobby/native/discord_disabled.txt`; remove that file to enable it.

### Changed

- Use **launcher 0.18.0** for Discord invites that need to start the game.
  Keep Discord desktop open with activity sharing enabled. No Discord SDK
  download or additional runtime DLL is required.

### Known issues

- Joining from another Discord account has not yet been verified end to end.
  Local presence and automated public-session and invite tests pass.
- Kills and deaths count events observed during your local session; joining
  late cannot reconstruct earlier events.
- Make a solo session public before starting its match. A private solo
  match that has already gone offline needs a fresh online session to be
  joinable.
