# Post-game and next-map voting

**Date:** 2026-10-02
**Summary:** Matches end with final standings, then everyone returns to the lobby together and votes on the next game. Nobody is dropped from the fireteam anymore.

### Added

- **The end of a match.** When someone reaches the score to win, the
  scoreboard shows the final standings on every screen, and a few seconds
  later the host takes the whole fireteam back to the lobby. Before, the
  game sent every guest to their own main menu and out of the fireteam.
- **A post-game screen** with the final standings and a 20-second vote on
  the next game: the same game again, or one of three other maps. Every
  player votes. The host can start the leading game right away, or go to the
  lobby to pick by hand. With no votes, the next map in the list plays.
- **Players who join see the host's lobby**, with the host's map and game
  type, instead of the game's CLIENT LOBBY screen.
- **A build line** at the bottom of the HUD and the multiplayer screens
  shows the mod versions and the game build, for screenshots and bug
  reports.
- **Slayer and Capture the Flag game types now ship with MJOLNIRLevelLoader.**
  Earlier releases left them out.

### Changed

- **MJOLNIRHud 0.3.0:** TO WIN shows the game type's real score to win. The
  match score sits at the top edge of the screen and is more transparent.
  The respawn countdown no longer gets stuck on a guest's screen.
- **MJOLNIRLobby 0.2.0:** the post-game screen, the vote and the guests'
  lobby view.
- **MJOLNIRLevelLoader 0.1.3:** the return to the menu no longer freezes
  guests, and no longer loads the old map's scenery on the way.

Update the CE runtime from the launcher's Multiplayer page (1.0.4) for the
post-game screen, the build line and the new match score position. Without
it, a match still ends together in the lobby, without the vote.
