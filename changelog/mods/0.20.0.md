# Download maps in game and join right away

**Date:** 2026-10-10
**Summary:** Join a server on a map you don't have and download it in game, with its screenshot and details: no restart, even to update to the host's version.

Needs MJOLNIR Launcher 0.12.0, which does the download and checks the map's
signature. The new screens and screenshots come with CE runtime pack 1.6.0.
With an older runtime pack the downloads still work, through a plainer
screen.

### Added

- **Download a map without leaving the game** (MJOLNIRLobby 0.10.0,
  MJOLNIRLevelLoader 0.5.1). When a game needs a map you don't have, a
  screen shows its hub screenshot, author, rating, downloads, size, version
  and game types. DOWNLOAD installs it from mjolnircore.com and loads it
  into the running game, and you carry on. Maps are signed by their authors
  and checked before they install. The screen comes up when:
  - you join a server from FIND GAMES (DOWNLOAD AND JOIN), including a match
    already under way;
  - the host picks a map you don't have, or the post-game vote does;
  - you press DOWNLOAD MAP in the lobby, if you closed the screen.
- **The host waits for downloads.** The lobby and the post-game screen say
  "WAITING FOR 1 PLAYER TO DOWNLOAD …". The vote's countdown holds for up to
  three minutes. In the lobby, a second START starts without them.
- **Everyone plays the host's version.** A player with another version of
  the map, older or newer, is offered an UPDATE to the host's exact version.
  It's applied in the running game: no restart.
- **Hub screenshots on the map screens.** The map select shows the
  screenshot, author, downloads and version. The lobby card, FIND GAMES and
  the post-game vote show the screenshot of the map they name.

### Fixed

- **Games with players who have different maps installed now start.** The
  game identifies a fireteam's map by its position in a list that differs
  between players. A host with a map a guest didn't have, or one installed
  later, loaded the world for everyone and never started it. The host now
  tells every player where the map is.
- **A player without the map no longer holds up everyone's start.** The
  host's first START names them, and a second START sends them back to
  their own menu. A player told the host is starting a map they don't have
  leaves the fireteam on their own.
