# A missing map part can't crash the game

**Date:** 2026-11-18
**Summary:** The loader no longer crashes when a map's moving part has no mesh, as happened on Containment 2.0.0.

### Fixed

In MJOLNIRLevelLoader 0.20.1.

- **No crash from a missing part.** Containment 2.0.0 shipped without its
  gates' meshes, and the game crashed a couple of seconds after the map
  loaded. Containment 2.0.1 puts the gates back; this loader also waits for
  a moving part's mesh instead of crashing when it is missing or still
  loading.
