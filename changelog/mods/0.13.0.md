# A new server browser in FIND GAMES

**Date:** 2026-10-03
**Summary:** FIND GAMES is now a proper server browser: columns that line up, sorting, filters, a details panel and QUICK JOIN.

### Added

- **Sort any column.** Server, map, game type, players, ping and status each
  get their own column, lined up down the list. Click a heading to sort by
  it, and click again to reverse. Ping, lowest first, is the default.
- **Filters.** Pick a game type or a map, or hide full games, matches under
  way and maps you don't have. The list says how many games your filters
  hide. Your sort and filters are remembered.
- **QUICK JOIN** puts you in the best open game your filters allow: one with
  a map you have and a free slot, preferring the same MJOLNIR version, a
  better connection and more players.
- **A details panel** for the game under the cursor or the one you picked:
  host, map, game type, a bar of player slots, ping, region and version, with
  a warning when you're missing the map or the host runs another version.
  JOIN tells you why it can't join (game full, map not installed).
- The list refreshes itself every 30 seconds while it's open, and holds up to
  40 games.

### Changed

- **MJOLNIRLobby 0.6.0**: the new FIND GAMES. The new screen comes with the
  CE runtime 1.0.6 from the hub. With an older runtime, FIND GAMES still
  works as before.
