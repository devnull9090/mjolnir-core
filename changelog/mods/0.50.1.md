# A smoother start to each match

**Date:** 2026-11-10
**Summary:** The HUD no longer freezes the game for a fifth of a second as a match begins: its setup is spread over the first second.

### Fixed

In MJOLNIRHud 0.20.1.

- **No freeze as a match starts.** In the first moment of a match the HUD
  made its kill feed, scoreboard, chat box and markers, and hooked the
  game's events, all in one go. That held the game for 162–285 ms. Now each
  piece gets its own tenth of a second, and everything is up by 0.8 s into
  the match. On two copies of the game, the longest the HUD held the game in
  a match's first 10 seconds went from 189 ms to 36 ms on the host, and from
  211 ms to 29 ms for the player who joined.
- **The HUD's widgets are loaded in the menus,** so the first match of a
  session no longer loads them as it starts.
- **Every match's start is measured.** The log says what the HUD's slowest
  moment in a match's first 10 seconds was and what it spent it on. Any
  moment that holds the game over 50 ms is logged with the same breakdown.
