# Mods that start on slower PCs, and no more Ctrl+R crashes

**Date:** 2026-10-03
**Summary:** UE4SS gets two minutes to start instead of 30 seconds, so mods run on slower PCs, and Ctrl+R no longer reloads every mod mid-game.

### Fixed

- **Mods no longer fail to start on slower PCs.** UE4SS waits for the game
  to finish starting before it hooks in. On some PCs that took longer than
  its 30-second limit, so it gave up and no mods ran. The multiplayer lobby
  still showed, but none of its buttons did anything. The launcher now
  raises the limit to two minutes in `UE4SS-settings.ini`, and leaves a
  longer limit you set yourself alone.
- **Ctrl+R no longer reloads every mod.** UE4SS's hot reload, meant for
  people writing mods, restarted every mod when Ctrl+R was pressed. In a
  match that crashed the host. The launcher now turns it off
  (`EnableHotReloadSystem = 0`).
- These are applied when the launcher opens and every time it starts the game,
  so it holds when you start the game from Steam too. Nothing else in your
  settings file changes.

### Notes

- If the lobby's buttons still do nothing, send us `ue4ss\UE4SS.log` from
  the game's `Meteorite\Binaries\Win64` folder.
