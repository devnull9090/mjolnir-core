# Installs the Halo 2 maps as an optional pack, apart from the CE maps

**Date:** 2026-10-24
**Summary:** Install multiplayer now installs only the Halo CE maps. The Halo 2 maps are a separate, optional pack with their own button.

### Added

- **Install Halo 2 maps.** The Multiplayer page has a second section for the
  official Halo 2 multiplayer maps, an optional pack of about 700 MB. Its
  button installs them all with what they need, and running it again
  updates the ones that moved on, the same way Install multiplayer does.
- Map tiles, on the Multiplayer page and in Browse Hub's Maps tab, say which
  game a map comes from (Halo CE or Halo 2) when the hub says.

### Changed

- **Install multiplayer takes only the Halo CE maps.** With the Halo 2 maps
  on the hub as official maps too, it leaves them out, so the classic set is
  no bigger to download than before.

### Security

- **Game types are checked before they install.** The launcher refuses a
  map or mod whose Megalo game type the game could not load safely, rather
  than install it.
