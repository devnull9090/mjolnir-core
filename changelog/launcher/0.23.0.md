# Maps can bring their own vehicle sounds

**Date:** 2026-11-06
**Summary:** The launcher installs the vehicle sound banks a map carries, after checking each one. No published map uses them yet, so this update changes nothing you can hear today.

### Added

- **Vehicle sounds from a map.** A map can now carry Wwise sound banks for its own
  vehicles, so they play through the game's audio and follow your volume sliders. The
  launcher installs them with the map, and update, repair, verify and uninstall all
  cover them. A bank missing from the cache shows up as a damaged install.

### Changed

- **Banks are checked before anything is written.** A release is refused if a bank is
  damaged, has the wrong id, or would replace one of the game's own, so a map can't
  change how a stock vehicle sounds on every other map.
- **A release carrying a `.pak` is refused.** The launcher builds the `.pak` a map's
  banks need itself, so a bank can only land where the game reads banks.
