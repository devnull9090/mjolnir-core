# Large maps download on any connection

**Date:** 2026-11-21
**Summary:** A map of several hundred megabytes no longer fails to install on a connection that needs more than three minutes to download it.

### Fixed

- **Large map downloads.** The launcher gave every download three minutes in
  all. The Pelican Warfare map is 685 MB, which needs 30 Mbit/s to arrive in
  that time, so on a slower connection the install stopped with an error. A
  map or content download now has an hour.
