# See your updates download

**Date:** 2026-10-08
**Summary:** Updates now shows each download's progress, speed and time left, with a speed graph of the last minute above the list.

### Added

- **Progress on every update.** A row that is updating shows a bar, how much
  has downloaded out of how much, its speed, and the time left. When the
  download is done it says "Installing" while the files are written.
  Finished rows show how much they downloaded.
- **A speed graph above the list**, in the style of Steam's downloads page.
  Download speed shows as bars and disk writes as a line, over the last
  minute. Beside it are the current and peak speed, the total downloaded and
  the disk speed. Below it, a bar for the whole batch shows how many updates
  are done and how long the run has taken. It stays up as a summary when the
  run finishes.

### Notes

- There is a time-left estimate for each update but not for the whole batch.
  The launcher only learns how big an update is when its download starts.
