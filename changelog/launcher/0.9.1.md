# One launcher, not two

**Date:** 2026-10-02
**Summary:** Updating no longer leaves a second copy of the launcher behind. Your shortcuts open the current version, and Installed apps lists it once.

### Fixed

- **Updates no longer install a second copy.** If you installed the launcher
  from the .msi download, every update put a separate copy beside it: two
  entries in Installed apps, and your shortcuts kept opening the old copy,
  which asked to update again. This update removes the old .msi copy;
  Windows asks for permission once to do it. Afterwards one launcher remains,
  updated in place, with its own shortcuts.
- **The download page gives the setup .exe**, the installer updates use, and
  its main button downloads the launcher itself. It used to open the newest
  GitHub release, which was often a mods release with no installer.
