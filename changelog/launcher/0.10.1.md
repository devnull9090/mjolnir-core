# No more UE4SS console window

**Date:** 2026-10-03
**Summary:** The black UE4SS log window no longer opens beside the game. Turn it back on under Settings if you want it.

### Changed

- **The UE4SS console is hidden by default.** UE4SS used to open a terminal
  full of log lines next to the game, which looked alarming if you didn't
  expect it. The launcher now turns it off before the game starts. The same
  log is still saved to `ue4ss/UE4SS.log`.

### Added

- **Settings → Troubleshooting → Show UE4SS console.** Turn it on to get the
  window back, for writing mods or reporting a problem. It takes effect the
  next time the game starts, including when you start the game from Steam.
