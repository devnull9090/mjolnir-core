# Multiplayer, in one click

**Date:** 2026-10-02
**Summary:** The new Multiplayer page installs the classic Halo CE maps and everything they need to play with your fireteam. Alpha.

The launcher now installs classic Halo: Combat Evolved multiplayer for Halo
Campaign Evolved. Open **Multiplayer** in the sidebar and press **Install
multiplayer**: it downloads every classic map from the hub, the shared CE
content they need, and the multiplayer mods, then registers the maps with
your game. Press it again later to update. In game, choose **MULTIPLAYER** on
the main menu.

### Added

- **The Multiplayer page.** It lists the classic maps, shows which are
  installed and current, and installs or updates them all at once.
- **Map packs from the hub.** A map installs like any other hub mod, along with
  what it depends on, and the launcher registers it with the game from your own
  game files. After a game update, the next launch registers the maps again
  before the game starts.

### Fixed

- Steam libraries outside the default Steam folder are found: the launcher now
  asks Windows where Steam is installed.
- Uninstalling the runtime also removes the map registration it built, so the
  game is left as shipped.

### Known issues

- Multiplayer is an alpha. Fireteams are limited to four players for now.
