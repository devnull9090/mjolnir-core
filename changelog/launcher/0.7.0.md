# See what a mod does before you install it

**Date:** 2026-08-11
**Summary:** Mod pages now show "What this mod does" — the declared list of every tag edit, texture, and script in the latest release — and mods the community reports are hidden automatically.

A mod page used to be whatever the author wrote about it, which for the first
community-published mod was nothing at all. You installed it to find out.

### Added

- A **What this mod does** section on every content mod's page: the change
  list the release declared at export — each tag field edit with the original
  value beside the new one, each replaced texture, each script.

### Changed

- Mods reported by three different accounts are hidden everywhere — delisted,
  page gone, downloads stopped — until a moderator looks. Before, a bad upload
  stayed up until a moderator happened to notice on their own.
