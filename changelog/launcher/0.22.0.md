# Launching works again after the mods 0.44.0 update

**Date:** 2026-11-06
**Summary:** Fixes launches that stopped with "Try again" after mods 0.44.0. This update installs itself, then finishes the update it could not complete before.

### Added

- **Game types that change a player.** The launcher now accepts game types whose
  scripts change how a player moves, hits or looks, which Stalker, Reverse Tag and
  the Juggernaut's extra damage in MJOLNIR mods 0.45.0 need.

### Changed

- **Update checks are quicker on a long map list.** The launcher asks about four
  mods at a time and keeps one connection to the hub, rather than asking about
  each mod in turn over a new connection.
- **The map browser's game type filter** lists the game types maps can offer.

### Fixed

- **The launcher could not finish updating MJOLNIRLevelLoader to 0.10.0.** Launcher
  0.21.0 did not recognise the new game types in mods 0.44.0 and refused them, so
  the update failed part way through, the launch stopped, and Try again failed
  the same way. Starting the game from Steam still worked. This launcher accepts
  them, and it finishes that update for you.
- **A refused mod is left as it was.** The launcher now checks every file in a mod
  before it writes any of them. Before, a file it refused part way through left
  the mod half-installed, which is what happened above.
