# The launcher updates itself first

**Date:** 2026-11-01
**Summary:** When the launcher is out of date it updates itself before anything else, then restarts and finishes the rest. A launch never starts an out-of-date game.

### Changed

- **The launcher updates itself first.** The check before a launch, the
  Updates screen and the game's own "out of date" prompt now include the
  launcher. When it is behind, it installs only the launcher and restarts.
  The new launcher then checks again, installs the remaining updates and
  starts the game (or, from the Updates screen, applies the rest of what you
  picked). Changes to how updates are installed are always in place before
  they are used.
- **No launching out of date.** When updates or damaged files are found, the
  launch dialog offers **Update and launch** and **Cancel**: everyone in a
  fireteam needs the same versions. A failed step offers **Try again**.
  Being offline still never blocks a launch, and neither do mods MJOLNIR
  did not install (you are still asked whether to move them aside).
