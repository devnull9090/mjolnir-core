# Straight to the main menu: the intro videos are skipped

**Date:** 2026-10-25
**Summary:** The game skips its start-up logo videos and reaches the main menu about 20 seconds sooner. Settings has a switch to turn the videos back on.

### Added

- **Skip intro videos**, on by default, under Settings > Troubleshooting. The
  launcher sets the start-up logo movie aside before each launch, so the game
  goes straight to its title screen (49 s to the main menu became 28 s on a
  test PC). Turning it off puts the movie back. It also holds when you start
  the game from Steam, and a game update or a file check that brings the
  movie back is handled at the next launch.

### Changed

- Dependency updates.
