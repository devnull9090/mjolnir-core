# Automatic updates work for the first time

**Date:** 2026-08-01
**Summary:** Fixes automatic updates, which had never worked in any released build: the launcher was silently blocked from checking, and reported the block as "up to date".

### Fixed

- **Automatic updates never ran.** The launcher's own permissions never allowed
  the update check, so the request was refused before it left the app — and the
  refusal was reported as "you are up to date". Every release since updates were
  introduced was affected.

  **Installs on 0.3.x and 0.4.0 need one manual install to recover.** The
  permission is compiled into the program, so the broken build cannot fetch the
  fix by itself. After this one manual step, updates work on their own.

- The header claimed a fixed MJOLNIR and UE4SS version regardless of what was
  actually installed. It now reports what is really there.
