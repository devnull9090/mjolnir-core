# Renamed mod files in mod folders are found

**Date:** 2026-11-21
**Summary:** The launcher no longer mistakes a mod for one of MJOLNIR's own files when it sits in the game's ~mods or LogicMods folder under a MJOLNIR-like name.

### Fixed

- **Mods named like MJOLNIR files are found.** Before each launch the
  launcher moves aside mods it did not install. It recognised MJOLNIR's own
  files by name in any folder under the game's Paks, so a mod renamed to look
  like one (`pakchunk1-MJOLNIR...`) and dropped into `~mods` or `LogicMods`
  was left in place, and the game loaded it. MJOLNIR installs its files in
  the Paks folder itself and nowhere below it, so a file with that name in a
  subfolder is now treated as a mod and moved aside with the rest.
