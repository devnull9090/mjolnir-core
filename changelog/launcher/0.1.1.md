# Automatic updates

**Date:** 2026-07-25
**Summary:** The launcher can now check for new versions and install them itself, instead of asking you to download a new installer by hand.

### Added

- Automatic updates. The launcher asks mjolnircore.com whether a newer build
  exists, downloads it, and verifies its signature before installing.

### Known issues

- Because the update check ships *inside* the launcher, 0.1.0 cannot use it.
  That build has to be replaced with this one manually, once.
