# The Windows installer builds again

**Date:** 2026-07-25
**Summary:** Fixes the Windows installer, which had stopped building since the branded artwork was added in 0.1.3, leaving several releases without one.

### Fixed

- The branded Windows installer failed to build, because its header and sidebar
  artwork were in a format the installer toolchain cannot read. Both are now
  bitmaps, and the Discord link on the finish screen is wired up the supported
  way.
