# A Tools tab, and the Tag Editor

**Date:** 2026-08-01
**Summary:** Adds a Tools tab that installs and updates companion apps on demand, starting with the new MJOLNIR Tag Editor for browsing and editing the game's tags and textures.

### Added

- **Tools.** A new tab that installs companion applications on demand. It
  downloads each tool, checks it against the SHA-256 its publisher advertises
  before anything lands on disk as an executable, and keeps it under the
  launcher's own data folder — so there is no second installer and no admin
  prompt.
- **The MJOLNIR Tag Editor**, installable from that tab. See its own
  [0.1.0 release notes](/changelog/tag-editor/0.1.0).

Tools update on their own schedule rather than riding along inside the
launcher, so the launcher installer does not grow with every tool added and a
tool can ship a fix without waiting for a launcher release.

### Fixed

- Automatic updates now actually carry a signature. Releases had been published
  without one, which the launcher correctly refused to install.
