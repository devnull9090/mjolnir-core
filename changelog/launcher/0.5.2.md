# Setup installs the mods a new install needs

**Date:** 2026-08-01
**Summary:** First-time setup no longer finishes with a modding framework and nothing to run in it, and the rest of the signed mods are now listed in My Mods with an Install button.

### Fixed

- **Setup left you with nothing installed.** The runtime bundle deliberately
  ships no mods, so a fresh setup produced a working framework loading zero
  mods — and the setup panel meanwhile listed five it had not installed. Setup
  now installs the framework mod the game needs, and the panel lists what setup
  actually does rather than a hardcoded paragraph.

### Added

- My Mods lists every signed mod you do not have installed, with an Install
  button. Developer tools like the scripting bridge and the engine dumper are
  listed rather than installed automatically — they evaluate arbitrary code or
  dump engine internals, and have no business arriving uninvited.

### Changed

- Installing several mods at once costs one request rather than one per mod.
