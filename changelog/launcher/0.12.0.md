# Installs maps for the running game

**Date:** 2026-10-10
**Summary:** The game can ask the launcher to install a map while you play, the same signed install the Maps tab does, so joining a server never needs a restart.

### Added

- **Map installs for the running game.** MJOLNIRLobby 0.10.0 starts the
  launcher without a window to install a map a game needs: one you don't
  have, or the exact version a host runs. It's the same install as the Maps
  tab: the hub's hash, the author's signature, and the same files and load
  order. Your next launch therefore has nothing to copy.
  - It never replaces a file the game has open. An update goes in beside
    the old copy, and the game swaps between them.
  - Any other copy of the same map is removed, so two versions are never
    loaded together.
  - Code mods aren't touched.
- **The launcher records where it's installed** each time it starts, so the
  game can find it. Open this version once after updating, and in-game
  downloads work from then on.
