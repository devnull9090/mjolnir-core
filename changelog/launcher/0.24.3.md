# Updated maps show their new game types

**Date:** 2026-11-21
**Summary:** A map update that adds game types now reaches the game's map list, so King, Oddball and Race appear on the eleven Halo: Combat Evolved maps updated on 21 November.

### Fixed

- **An updated map lists its new game types.** The game's multiplayer menu
  reads each map's game types from a list the launcher writes. The launcher
  wrote that list again only when you installed or removed a map, or when the
  game itself was updated. An update to a map you already had left the old
  list in place, so the map loaded the new version but the menu still offered
  the old game types. The eleven Halo: Combat Evolved maps updated on
  21 November (Blood Gulch, Battle Creek, Danger Canyon, Death Island,
  Gephyrophobia, Ice Fields, Infinity, Sidewinder, Timberland, Rat Race and
  Yoyorast Island) showed only Slayer and Capture the Flag for this reason.
  The launcher now writes the list again whenever a map's files change. The
  first start from this version takes a few seconds longer, once, while it
  brings every installed map up to date.
