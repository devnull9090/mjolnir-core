# Open public games from Discord

**Date:** 2026-10-24
**Summary:** Discord's Join Game can open MJOLNIR and start Halo Campaign Evolved, using the launcher's usual sign-in, map and update checks.

### Added

- **Launch from Discord.** Run the updated launcher once to register its
  Discord launch link. Clicking Join Game on a public MJOLNIR session can
  then start the game if it is closed. The normal update and file checks
  run before launch; a game already running is kept open.
- Works with **code mods 0.36.0**, which publish MJOLNIR Core presence and
  receive public-session invites. Keep the Discord desktop app running
  and enable activity sharing. No Discord SDK installation is needed.

### Known issues

- Joining from another Discord account, including a join that starts a
  closed game, has not yet been verified end to end. Local presence and
  automated invite handling tests pass.
- If game startup or required downloads take more than about three minutes,
  click Join Game again after the game is ready. An invite received while
  playing waits until you return to the main menu.
