# Puts back the remastered maps' grass

**Date:** 2026-10-17
**Summary:** Remastered maps installed by launcher 0.13 had no grass or decals. The launcher now finds those maps and downloads them again from Updates.

### Fixed

- **Remastered maps with no grass.** "Update all" in launcher 0.13 updated
  the maps before it updated the launcher, and that launcher left out each
  map's grass and decal files. Launcher 0.14.0 did not fix those installs,
  because the maps were already at their newest version. The launcher now
  checks that every file a map's level needs is there. A map that is missing
  one shows in Updates as a repair, which downloads the same version again,
  and the Multiplayer page offers to install it.
