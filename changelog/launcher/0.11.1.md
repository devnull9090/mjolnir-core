# Multiplayer shows what you have installed

**Date:** 2026-10-08
**Summary:** Multiplayer stops offering updates you already installed from Updates, and each map shows its installed version.

### Fixed

- **No more false "Update" badges on Multiplayer.** After you ran every
  update on the Updates tab, Multiplayer still marked each map "Update"
  until you restarted the launcher. The two tabs now refresh each other
  after an install, so each one reflects what the other just did.
- **Multiplayer decides "Update" the way Updates does.** A map needs an
  update only when the hub has a newer version than the one you have.
  Install multiplayer uses the same rule, so it does not download a map
  again that Updates just brought up to date.

### Added

- **Map versions on Multiplayer.** Each map card shows the version you have
  installed, or `v1.2.0 → v1.3.0` when a newer one is out. A map you have
  not installed shows the version on the hub.
- **A "Files missing" badge** for a map that was installed but whose files
  were deleted. Install multiplayer puts them back.
