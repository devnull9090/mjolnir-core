# Community maps, covers, and links from the website

**Date:** 2026-10-10
**Summary:** A Maps tab to find community maps by game type, size and players; screenshots on every mod; and Join and Install buttons on mjolnircore.com that open the launcher.

### Added

- **Maps tab in Browse Hub.** Every map on the hub, with its screenshot:
  search by name or code, and filter by classics or community, game type,
  size, vehicles, and how many players it suits. Sort by newest, downloads,
  rating or name. Each map installs with one click.
  - Install multiplayer still installs only the 19 classic maps. Community
    maps install when you choose them, or in game when a server needs one.
  - Maps have moved out of Content mods into this tab.
- **Screenshots in Browse Hub.** Every mod card shows its cover, and a
  mod's page shows its gallery. Screenshots on mod pages didn't load in the
  launcher before.
- **Links from mjolnircore.com.** The launcher opens when you press:
  - **Join** on the Games page or Match history. It checks the server is
    still up, starts the game if it isn't running, and the game joins from
    the main menu. Without multiplayer installed, it offers to install it
    first.
  - **Install in launcher** on the Maps page, or **Open in launcher** on a
    mod's page, to open that map or mod here.
- **One launcher window.** Opening the launcher again, or a link, brings
  the open window forward instead of starting a second copy.
