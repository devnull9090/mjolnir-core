# A new Home screen

**Date:** 2026-11-27
**Summary:** The launcher opens on a new Home screen with one-click Play, live public games, recent matches and the newest mods. The rest of the launcher has a refreshed look.

### Added

- **Home.** The launcher now opens on a Home screen. It shows whether your
  install is ready, a Play button, the public games running right now,
  recent match reports and the newest community mods from the hub. You can
  join a game or open a mod from there.
- **Live counts in the sidebar.** The sidebar shows how many public games
  are live and how many updates are waiting.

### Changed

- **Refreshed look.** The sidebar, header, map tiles, Multiplayer, Browse
  and Tools screens are redrawn, and every dropdown now uses the same
  MJOLNIR-styled menu instead of the system one.
- Hub information is fetched in one place and refreshed every 30 seconds.
  If you are offline the launcher works as before: your mods and Launch are
  unaffected.
