# Installs the remastered classic maps

**Date:** 2026-10-17
**Summary:** The launcher installs the remastered classic maps, with their grass and decal files, and updates the CE runtime pack they need. Update the launcher first.

### Added

- **Maps that carry more than a level.** A remastered map comes with its
  grass and decal files beside its level. The launcher installs them with
  the map, keeps them up to date, and removes files a newer version of the
  map no longer has. This works for maps installed in game too.

### Changed

- **Dependencies are kept up to date.** When a map needs a newer CE
  runtime pack than the one installed (the remastered maps need 1.8.0), the
  launcher now updates the runtime pack when it installs the map. Before,
  the map ran against the older runtime pack and drew without its new
  materials.
- **A clearer message in game.** Downloading a map in game when your
  runtime pack is too old now says which version the map needs and which
  one you have, instead of saying the runtime pack is not installed.
