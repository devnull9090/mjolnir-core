# The first MJOLNIR Launcher build

**Date:** 2026-07-25
**Summary:** The first published build of the MJOLNIR Launcher for Halo Campaign Evolved, alongside the mjolnircore.com website and the automated release pipeline behind both.

This is where the platform starts. The launcher is a Tauri desktop app that
finds your copy of Halo Campaign Evolved and manages the UE4SS modding
framework for you, and mjolnircore.com is the site that documents and
distributes it.

### Added

- A desktop launcher that detects an installed copy of the game and drives the
  modding framework from a single window, rather than through hand-copied files.
- The mjolnircore.com website: landing page, mod browser and the download page.
- Signed, checksummed Windows installers published automatically whenever a
  release is tagged, so every download can be verified against a published
  SHA-256.
- MJOLNIRFlyCam, a free debug camera for flying around the campaign.

### Known issues

- Automatic updates are not wired up yet. This build cannot update itself and
  has to be replaced by hand.
