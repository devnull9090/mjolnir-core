# Launching the Xbox app version

**Date:** 2026-10-10
**Summary:** Play now starts the Xbox app (Game Pass) version of the game, instead of asking for an app to open an ms-xbl link.

### Fixed

- **Launching the Xbox app version.** With the game installed through the
  Xbox app, Play opened Windows' "Get an app to open this
  'ms-xbl-9n683tdt5m7r' link" prompt. The launcher now starts the game the
  way the Start menu does, by its app id from the install's own manifest.
