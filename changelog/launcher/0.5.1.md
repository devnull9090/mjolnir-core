# The signed badge tells the truth, and updates install quietly

**Date:** 2026-08-01
**Summary:** Mods installed by an earlier launcher now verify as signed instead of reading unverified forever, and automatic updates stop interrupting you with an installer prompt.

### Fixed

- **Mods installed before 0.5.0 read as unverified permanently.** The badge
  asked the launcher's own records, which those installs never had, instead of
  asking the signed set whether the files on disk match. It now asks the set.
- Automatic updates no longer stop halfway to ask you to confirm an install.
  The Windows installer prompts before replacing an existing copy unless it is
  told to run silently, and it now is. This takes effect for updates *from*
  0.5.1 onward — the build doing the updating is the one that decides.

### Changed

- "Unmanaged" is shown as a neutral state rather than a warning. It is the
  ordinary condition of every mod UE4SS ships with, not a problem.
