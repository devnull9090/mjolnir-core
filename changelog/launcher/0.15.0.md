# Offers to send crash reports, and restarts mods UE4SS stopped loading

**Date:** 2026-10-17
**Summary:** When the game crashes, the launcher offers to send a crash report so we can find the cause. It also repairs mods that stopped starting.

### Added

- **Crash reports.** When the game crashes, a bar at the top of the launcher
  asks whether to send a report to the MJOLNIR team. Nothing is sent unless
  you click Send report. "What's sent?" lists what goes: where the game
  crashed, a trimmed crash dump without the game's memory, the UE4SS log from
  that session, and your installed mods. Your PC's and Epic account's IDs and
  your Windows user name are removed first. Sending needs the hub sign-in.
- For a crash that is new to us, the launcher then asks whether you will also
  send the full crash dump, about 50 MB. It is a copy of the game's memory
  when it crashed, so it is only ever sent on that second yes.
- **Settings → Crash Reports** lists your recent crashes, each with a Send
  button. Crashes from before this update are listed there but never asked
  about.

### Fixed

- **"MJOLNIR MODS DID NOT START" in the multiplayer lobby.** When a mod's line
  went missing from mods.txt, UE4SS stopped starting that mod and the launcher
  could not put it back. Switching a mod on now adds its line, so installing a
  map or "Install multiplayer" repairs the file. Script mods now also lists mod
  folders that mods.txt leaves out, so you can switch them on.
