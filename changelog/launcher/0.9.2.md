# Maps you deleted show as missing

**Date:** 2026-10-02
**Summary:** A map whose files were deleted no longer shows as installed. The Multiplayer page offers it again, and launching puts missing files back.

### Fixed

- **Deleted maps no longer show as installed.** The Multiplayer page went by
  the launcher's own record, so a map whose files were deleted from the
  game's Paks folder still read "Installed" and the install button stayed
  greyed out. It now checks the files are there, and offers anything missing
  again.
- **Launching the game puts missing hub files back.** If a map or mod you
  installed from the hub is missing from the Paks folder, the launcher copies
  it back before the game starts. When nothing is missing, launching copies
  nothing.
- **Install multiplayer re-downloads a map whose download was deleted**
  instead of counting it as up to date.
