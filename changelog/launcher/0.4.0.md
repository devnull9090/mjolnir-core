# The hub release: browse, rate and update mods in the launcher

**Date:** 2026-08-01
**Summary:** The launcher becomes a full hub client: mod pages, ratings and comments built in, one Updates screen for everything, and sign-in by pairing.

Three questions, three homes: what is installed, what exists, and what is out
of date.

### Added

- **My Mods** — everything installed, in one place. Content mods with their
  load order, script mods with their on/off switches.
- **Browse Hub** — the full mod catalogue with real mod pages: screenshots,
  descriptions, releases, ratings, reviews and comments, rendered by the same
  components the website uses.
- **Updates** — the launcher, the core install, content mods, script mods and
  tools in one list. Tick what you want, update all or update some, and a
  failure on one row does not stop the others.
- **Sign in by pairing.** The launcher shows a short code that you approve at
  [mjolnircore.com/link](https://mjolnircore.com/link) in your browser. Nothing
  is typed into the launcher, and the key it receives can rate and comment but
  cannot publish. It is held by the launcher's background process and is never
  exposed to the page.

### Security

- Every content mod is checked against the hub's recorded hash before anything
  is written to disk, and the hash of each unpacked file is recorded so a later
  check can spot a modified install.
- Where a release carries a signature, it must verify. Script mods continue to
  install only from the signed set built in this repository.
