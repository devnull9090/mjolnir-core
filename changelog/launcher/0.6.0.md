# Point the launcher at your game

**Date:** 2026-08-04
**Summary:** If MJOLNIR cannot find Halo Campaign Evolved, you can now choose the folder yourself instead of being stuck on the Game Not Found screen.

The launcher only ever knew where the stores usually put the game. A library on
a drive it did not guess, an install that had been moved, or a copy kept outside
a store meant Game Not Found — and that screen offered nothing but a link to the
store page for a game you already owned.

### Added

- **Game Location** in Settings. Choose the folder holding the game, and
  everything follows it: installing the runtime, managing your mods, verifying
  an install, launching.
- The same chooser on the Game Not Found screen, so the screen that reports the
  problem is also where you fix it.
- The picker takes whatever names the installation — the game folder, the
  library folder above it, the `Meteorite` folder inside it, the `Win64` folder,
  or the game's executable. It works out the rest.
- A **What's new** summary when an update finishes, so you can see what you just
  installed.

### Changed

- A folder that is not the game is refused when you choose it, with a note
  saying what was expected, rather than accepted and then failing partway
  through an install.
- A location you set is used as given. If that folder later disappears — an
  unplugged drive, a moved install — the launcher says so, instead of quietly
  finding some other copy of the game and installing into that. One click puts
  it back to detecting automatically.
- A location set here is passed to the tools the launcher starts, so the Tag
  Editor opens the same installation without being told a second time.

Thanks to **Feb** on Discord, whose report is the reason this release exists.
For anyone whose game was not where the launcher expected, it was not a rough
edge — the launcher did nothing at all, and there was no way to tell it
otherwise.
