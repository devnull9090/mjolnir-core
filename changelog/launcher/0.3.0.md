# Install, verify and toggle the mod framework from the launcher

**Date:** 2026-07-25
**Summary:** The launcher now installs the UE4SS modding framework for you, verifies every file it wrote, and supports Game Pass copies of Halo Campaign Evolved as well as Steam.

The first release that does the job the launcher exists for. Before this it
could find your game; now it can set it up.

### Added

- **One-click setup.** A first-run panel downloads the modding framework,
  installs it into your game directory and reports progress as it goes.
- **Verification.** Every installed file is checked against a published SHA-256,
  so you can tell an intact install from a damaged one.
- **An off switch.** Mods can be disabled and re-enabled without uninstalling
  anything, for when you want to play the game as shipped.
- **Uninstall**, which removes what the launcher put there and nothing else.
- **Game Pass support.** Game Pass installs are detected automatically, joining
  Steam and pointing the launcher at a game executable by hand.
- **A settings page** for launch options, re-verification and uninstall.

### Fixed

- Mod descriptions containing brackets or separator lines no longer render
  mangled in the mod list.
