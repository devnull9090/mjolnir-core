# Your hub sign-in, always in view

**Date:** 2026-10-02
**Summary:** The hub sign-in is in the header on every page, and the launcher tells you when it needs renewing. Public multiplayer games in the game use it.

### Added

- **A sign-in check at startup.** The launcher asks the hub whether its
  sign-in still works. If you aren't signed in, the sign-in expired or was
  revoked, or it expires within two weeks, a banner says so with the button
  that fixes it. Public multiplayer games (PUBLIC GAME and FIND GAMES in the
  game) need a working sign-in.

### Changed

- **The account button is in the header**, on every page, instead of only on
  Browse Hub.
- Sign-ins made before public games can list a game too. Nothing to do.
