# Update notifications you cannot miss

**Date:** 2026-07-25
**Summary:** Fixes automatic updates, which could not verify a download and so never installed one, and adds an update badge that persists after you dismiss the banner.

### Fixed

- Automatic updates could not complete. The launcher had no way to fetch the
  signature it verifies a downloaded update against, so every update failed
  verification.

### Added

- Dismissing the update banner no longer hides the update. A badge stays in the
  sidebar, and clicking it starts the update again.
- Failed updates offer a retry instead of leaving you to restart the launcher.
