# Checks before every launch, and moves other mods aside while you play

**Date:** 2026-10-24
**Summary:** Launch now checks for updates, checks your installed files and offers to move unsupported mods aside, showing every item as it goes.

### Added

- **A check before every launch.** Launch looks at the MJOLNIR core, each
  code mod, the CE runtime pack and every installed map. It lists anything
  out of date and any installed files that no longer match what was
  installed. **Update and launch** fixes them first; **Launch without
  updating** goes straight in. Every item shows as it is checked, under one
  progress bar, and each download shows its progress. What was installed is
  checked again before the game starts.
- **Unsupported mods moved aside.** Pak mods in the game's Paks folder and
  UE4SS mods that MJOLNIR did not install can break multiplayer for the whole
  fireteam. Launch lists them and offers to move them into a
  `MJOLNIR-set-aside` folder in the game folder while you play. They move
  back when the game closes, or the next time the launcher starts. Nothing is
  deleted, and every move is logged.
- **Update from inside the game.** When the game says it is out of date and
  you choose UPDATE AND RESTART, the launcher opens, waits for the game to
  close, updates, and starts it again (`mjolnir://update`).
- A join from a website link that has to start the game runs the same
  check first.

### Fixed

- A code mod that writes files into its own folder while the game runs no
  longer reads as changed: the check compares only the files its release
  shipped.
