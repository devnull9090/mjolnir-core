# See what a squad spawns, and pick palette entries by name

**Date:** 2026-10-10
**Summary:** Selecting a spawn point shows the units, weapons and vehicle its squad cell spawns, and every block index in the form is a dropdown of named entries.

A squad cell says what it spawns as palette numbers: `character type #2`,
`weapon type #1`. This release turns those numbers into names, both where
you place spawn points and in the form.

### Added

- **What a cell spawns, in the World view.** Selecting a spawn point lists
  what its squad cell spawns: the actor types with their odds (`crewman 50% ·
  crewman_female 50%`), the weapon, secondary weapon, equipment and vehicle,
  and the upgrade when it is not normal. When the spawn point overrides the
  cell's actor, weapon or vehicle, that is shown too.
- **Block indexes by name, in every tag.** A field that points at an entry
  of another block — a cell's character type, a weapon's magazine or barrel,
  an animation node's parent, a unit's seat — is now a dropdown of that
  block's entries, named the way the block's own list names them
  (`2 · crewman`). Choose one to change it. An index that points past the
  end of its block is shown in red.

### Notes

- A block with more than 512 entries, or one only partly read, keeps the
  text box, with the current entry's name beside it.
- "Custom" block indexes, such as a spawn point's `cell`, stay as numbers.
