# No Oodle DLL required

**Date:** 2026-08-02
**Summary:** The Tag Editor now reads the game's compressed containers on its own, so you no longer need to supply a proprietary Oodle DLL before it will open anything.

### Changed

- **The Oodle DLL is no longer required.** A decompressor is built into the
  editor and used by default. If you have `oo2core_*_win64.dll` it is still
  supported as a faster alternative, but nothing waits on it now.

  Verified byte-identical to the proprietary decoder across 56,002 compressed
  blocks in all 28 of the game's containers, and separately across every shipped
  tag.

### Fixed

- Mods whose asset count landed on a power of two produced an archive the game
  could not read. Four-asset mods were the common case.
