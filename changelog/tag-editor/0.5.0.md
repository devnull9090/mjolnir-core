# Live tag editing in the running game

**Date:** 2026-08-03
**Summary:** Change a tag value and see it in Halo Campaign Evolved immediately — no rebuild, no repacking, and no restarting the game.

### Added

- **Live editing.** With the game running, change a tag value in the editor and
  it takes effect there and then. The loop that used to be edit, build, install,
  relaunch and walk back to where you were is now edit and look.

### Fixed

- **Mods whose asset count was a power of two produced a broken archive.** The
  lookup table the game uses to find assets overflowed, and the result could not
  be read at all. Four-asset mods were the common case.
