# Spawn points you can move in the World view

**Date:** 2026-10-10
**Summary:** Spawn points in a scenario's World view can be selected, dragged, turned and duplicated, with the squad's actor count beside them.

The World view has drawn each squad's spawn points for a while, but they
could not be touched. Now they can, which makes adding enemies to a mission
a visual job rather than a column of coordinates.

### Added

- **Click a spawn point** to select it. The move and rotate gizmo works on it
  just as it does on a vehicle or a piece of scenery; turning only changes
  which way it faces. The new position and facing are recorded like any
  other edit, so they go into your mod and can be undone.
- A panel shows the point's squad, its name, and the designer cell it
  belongs to, with **−** and **+** to change how many actors that cell
  spawns (`normal diff count`) and how many spawn points the cell has.
- **dup** copies the selected spawn point a step to its side, in the same
  squad and cell, and selects the copy so it can be dragged into place. The
  copy has no name, so a script that names the original still finds just
  the one.

### Fixed

- Every squad's spawn points were drawn in the same colour, because squad
  names came back empty. Each squad now has its own colour.
