# Choose which installation you are editing

**Date:** 2026-08-04
**Summary:** The setup form now takes the game folder itself, and the installation you have open is named at the bottom of the left panel, with a way to change it.

### Added

- The open installation is named at the bottom of the left panel, with
  **change** beside it. Switching to another copy of the game previously meant
  finding and editing a settings file by hand.
- A **What's new** summary the first time the editor runs after it updates
  itself.

### Changed

- The game field takes anything that names the installation: the folder named
  after the game, the Steam library holding it, its `Meteorite\Content\Paks`
  folder, or a container inside it. It used to accept only the exact Paks path,
  which is rarely the folder anyone reaches for first.
- A folder with no game containers in it is refused when you choose it, rather
  than accepted and then failing when the catalogue is read. An empty `Paks`
  folder left behind by an uninstall is no longer mistaken for an installation.
- Opened from the launcher, the editor starts on whichever installation the
  launcher is set to. A folder you choose here is remembered and stays chosen.
