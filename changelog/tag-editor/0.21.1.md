# Blocks open past their first 64 elements

**Date:** 2026-10-10
**Summary:** A block with more than 64 elements now shows and edits every one of them, so a scenario can take more vehicles, scenery or squads than the first 64.

A small release: one fault in the form view, reported by a community member
adding vehicles to Two Betrayals.

### Fixed

- The form read at most 64 elements of a block. Past that, the element
  dropdown said "… 1 more not loaded" and the extra elements could not be
  selected or edited. Two Betrayals ships 61 vehicles, so the fourth vehicle
  added was stuck. Picking any element now reads the page of the block that
  holds it, and its fields can be edited like any other.
- The dropdown lists every element of a block up to 4,096 long. A longer
  block, such as a BSP's surfaces, has a **go to** box for typing an element
  number.
- **copy** works on an element past the 64th; it used to fail.
- The Tree view shows the same page, labelled with the elements it covers.

Copy Block as TSV still copies only the first 64 rows of a longer block.
