# The Script, World and Model views keep the way back

**Date:** 2026-09-12
**Summary:** The Script, World and Model views keep the view buttons, so there is a way back to a tag's fields, and a view chosen for one tab no longer follows you into the next.

A small release: two navigation faults in the tag views, and live mode
finding the game under an Xbox app install.

### Fixed

- Switching a scenario to **Script** or **World**, or an object to **Model**,
  left no way back. Those views did not draw the header that holds the Form,
  Tree, Script, World and Model buttons, so the fields could only be reached
  by opening the tag again. The header now stays on every view.
- The view was one setting for the whole editor, so after choosing Script for
  one scenario, every scenario opened afterwards came up in Script too, and a
  tag that has no script showed its form with nothing highlighted. Script,
  World and Model are now the choice of the tab they were picked in; opening
  another tag shows its fields. Form or Tree stays the remembered preference,
  as before.
- Live mode finds the game's executable under an Xbox app install, whose
  build sits in a `WinGDK` folder rather than the Steam build's `Win64`.
