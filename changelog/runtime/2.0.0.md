# Republished so existing installs are offered the migration

**Date:** 2026-08-01
**Summary:** The same bundle as 1.0.0, republished under a new major version so that installs still carrying the old modpack are actually offered the upgrade.

### Changed

- **Version only. The contents are identical to 1.0.0.**

  The modpack this replaces always declared itself version 1.0.0, and the
  launcher decides whether an update exists by comparing that number. Publishing
  the runtime as 1.0.0 meant every existing install compared equal and would
  never have been offered the migration at all.

  2.0.0 also states the truth: the bundle no longer contains mods, which is a
  breaking change for anything that expected them inside it.
