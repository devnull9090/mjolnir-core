# No console window on a fresh install

**Date:** 2026-10-03
**Summary:** A fresh install no longer opens UE4SS's console window beside the game. Launcher 0.10.1 has a setting to turn it back on.

### Changed

- **`ConsoleEnabled = 0` in the bundled `UE4SS-settings.ini`.** UE4SS used to
  open a terminal full of log lines next to the game, which alarmed players
  who didn't expect it. The same log is still written to `ue4ss/UE4SS.log`.

### Notes

- **Existing installs are not changed by this release.** `UE4SS-settings.ini`
  is seed state, so reinstalling keeps the copy you already have. Launcher
  0.10.1 sets the key itself every time it starts the game, from its new
  Settings > Troubleshooting > Show UE4SS console switch (off by default).
- Nothing else in the bundle changed: same UE4SS build, same signatures, same
  infrastructure mods as 2.0.1.
