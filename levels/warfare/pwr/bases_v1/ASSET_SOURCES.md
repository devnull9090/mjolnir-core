# Base art sources

This is a Blender authoring package. It has not been installed into the game.

The base shell, gallery portals, access ramps, roof socket, fins, trim and glyphs are authored for this project. Early iterations used a silver/dark/trim atlas generated with the built-in image generation tool. Final armor uses two verified native **2048 × 2048** maps, `T_FR_Diagonal_01_N` and `T_FR_Diagonal_01_ORHG`, from existing local Halo Campaign Evolved exports, combined with authored color, roughness and weathering nodes. The normal map's BC5 RG encoding is reconstructed for Blender and its DirectX green channel is flipped; the ORHG green channel provides roughness. This is not a claim of native albedo reproduction. Source files, hashes, encoding and metric UV policy are recorded in [native-finish-provenance.json](C:/Users/will/.codex/worktrees/pelican-warfare/haloce/levels/warfare/pwr/bases_v1/textures/native-finish-provenance.json).

The design concepts were generated from an existing project screenshot and then an actual Blender render. The [primary concept prompt](C:/Users/will/.codex/worktrees/pelican-warfare/haloce/.dream-loop/bases-v1/prompt-team-base.txt), [refinement prompt](C:/Users/will/.codex/worktrees/pelican-warfare/haloce/.dream-loop/bases-v1/prompt-team-refined.txt) and [early atlas prompt](C:/Users/will/.codex/worktrees/pelican-warfare/haloce/.dream-loop/bases-v1/prompt-alloy-atlas.txt) are retained. Concept images are design targets; the v16 delivery views are actual Blender renders of the authored geometry.

The native corridor-wall modules, pillar trims, presentation Warthog, pine mesh and ground textures come from the user's existing local Halo project/game extraction. Their source paths and SHA256 hashes are recorded by the stock module and staging receipts. They are not represented as newly licensed redistributable assets. Each final base retains eight native corridor panels and four native pillar trims. The large native rear-gallery wall sheets are no longer placed: one retained view-dependent artifacts after normal repair. Both gallery terminals now use project-authored recessed bulkheads, polygonal armor surrounds, engraved fields and integrated lights.

The cached stock-wall import contained inverted custom corner normals. [stock_interior.py](C:/Users/will/.codex/worktrees/pelican-warfare/haloce/levels/warfare/pwr/bases_v1/stock_interior.py) retains authored split-normal smoothing, corrects the global sign when the face/corner comparison establishes inversion, then corrects remaining minority hemisphere outliers. Vertex positions and face winding stay unchanged. Before/after diagnostics and repaired-corner counts are stored in each mesh's `stock_custom_normal_diagnostics` and the collection's `stock_interior_manifest`; linked team instances reuse the corrected mesh data.

Presentation lighting uses **Kloofendal 48d Partly Cloudy (Pure Sky)** by Greg Zaal and Jarod Guest, from [Poly Haven](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky), [CC0](https://polyhaven.com/license). The 2K EXR download was verified against the provider's MD5 `299976fb6e389e5349fabe80cf746b48`. This is a lighting asset for the Blender review, not an in-game sky change.

Visual research: [CE architecture artist analysis](https://tsce.info/postmortem-2015-silicon.html), [Danger Canyon reference](https://www.halopedia.org/Danger_Canyon), [beacon tower reference](https://www.halopedia.org/Beam_emitter), and [Halo Infinite environment artist portfolio](https://sharlene.artstation.com/projects/3dNWXB). These are references, not copied textures or models. The exact intended rooftop light-cannon asset remains unconfirmed; the socket is a removable design reservation.
